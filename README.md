# sales_model_restructuring_and_sales_analysis

This is Power BI project divided into 2 parts:
1. Data model restructuring:
Turning messy data model with 20 tables to snowflake schema of ... tables. Change any many-to-many relationships into one-to-many relationships, remove irrelevant data and introduce complementary data.

2. Sales data analysis
Analyze the overall sales status over two years. Detect any anomalies in the sales and give recommendations.
